The folder that the website folders (instagram.com, github.com, …) are created in. Missing folders are created automatically. Use \ or / between folders, e.g. Media\Social.

Chrome only lets extensions save inside its Downloads folder, so this is a folder inside it. To save on another drive or folder, change Chrome's own download location under Settings → Downloads.

Photo and video dates (exiftool)

Sets DateTimeOriginal, AllDates, CreationTime and ModifyDate to the time the post was published (the createdDate in the filename, in UTC, without a time zone). Profile pictures and other downloads are left alone.

Chrome extensions cannot run programs themselves, so this needs the small helper in the extension's native folder installed once: install.bat on Windows (needs Python 3), ./install.sh on Linux. Windows: use exiftool.exe (rename exiftool(-k).exe). Linux: the Image-ExifTool folder works as is (needs Perl).

Diagnose mode

Turn on only while checking why downloads stopped working. It does nothing extra while off.

While on:

  • Every Instagram call and its result is logged in the page console (F12, filter mediadownloader).
  • Error messages include the technical detail (which query, which id, what Instagram answered).
  • When a query fails, the current query id is looked up in Instagram's own scripts, retried once, and remembered.
