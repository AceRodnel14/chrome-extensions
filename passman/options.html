Passman

Connect this extension to your self-hosted passman. Sign in to passman in a normal tab; the extension reuses that session and never sees your login password.

This address uses plain http. Anyone on the network between you and the server can read your session and your passwords. Use https unless the server is on this computer.

Saved-sites list

Passman sends this extension a list of the sites you have entries for (names and addresses, no usernames or passwords). The extension keeps it on this computer, in this browser profile, and checks the pages you visit against it locally. Passman is contacted only when you act: opening a passman tab, Refresh now, opening the popup when the list is old, or clicking an entry to fill.

Once the list is older than this, the next popup open or fill refreshes it. Nothing is requested on a timer.

Export backup

A backup without a backup password is a plain JSON file that contains all your passwords in clear text. Set a backup password to get an encrypted zip, and keep the file somewhere safe.
